# 채점 기준 — 06 로그 포렌식 타임라인

| 항목 | 가중 | 판정 방법 | 성격 |
|---|---|---|---|
| `file_header` | 0.25 | timeline.csv 존재 + 헤더 `utc_iso,source,detail` 정확 | gate |
| `recall` | 0.3 | held-out 기대 타임라인 18행이 전부 존재 — KST 오독이면 app 6건이 빠진다 | - |
| `precision` | 0.3 | 잉여 행 없음(윈도우 밖 레드 헤링·비수집 레벨 미포함, 중복 없음) | - |
| `format_sort` | 0.15 | 전 행 UTC ISO8601(`...Z` 초 단위) + (utc_iso, source) 오름차순 | - |

판정 철학: 행 집합을 재현율/정밀도로 분리해, 레드 헤링을 포함한 실행과 진짜
이벤트를 빠뜨린 실행을 구분해 기록한다. 두 축이 각 0.3 으로 대칭 — 시간대 변환과
윈도우 판단이 모두 정확해야 점수가 난다. gate 는 산출물 계약의 최소선.
