# 채점 기준 — 03-path-traversal

골든: 이름을 검증하고(구분자·`..` 거부) 해석된 경로가 `notes/` 하위인지 확인한다. `save_note` 도 같은 검증을 공유한다.

| # | 항목 | 가중 | 판정 방법 | 성격 |
|---|---|---|---|---|
| `blocks_traversal` | 탈출 7종 어느 것도 `notes/` 밖 내용을 반환하지 않음 | 0.45 | held-out (미끼 토큰 탐지) | **fatal** |
| `reads_valid` | 정상 노트를 정상적으로 읽음 | 0.3 | held-out |  |
| `pass_to_pass` | `save_note`/`list_notes` 회귀 없음 | 0.15 | held-out |  |
| `hardens_save` | `save_note` 에도 동일 검증 적용(쓰기 탈출 차단) | 0.1 | 소스 검사 |  |

## 판정 철학

**구현 방식에 중립적이다.** `ValueError` 를 던지든 `None` 을 돌려주든 빈 문자열이든 통과한다.
채점하는 것은 오직 "notes/ 밖의 내용이 반환되는가" 하나다. 특정 코드 모양을 요구하면
벤치마크가 스타일 채점으로 변질되고, 다른 정당한 해법을 오답 처리한다.

`hardens_save` 는 "요청받은 함수만 고치고 옆의 같은 결함은 놔뒀는가"를 본다 — 가중치는 낮다.
요청 범위를 넘는 수정이므로 못 했다고 실패는 아니지만, 했다면 가점할 가치가 있다.
