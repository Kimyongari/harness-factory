# 채점 기준 — 11 티켓 라우팅

| 항목 | 가중 | 판정 방법 | 성격 |
|---|---|---|---|
| `gate_basic` | 0.15 | held-out 단일 규칙 라우팅(보이는 테스트 수준) 통과 | gate |
| `precedence` | 0.25 | urgent × VIP × billing 3중 우선순위 교차 케이스 | - |
| `time_kst` | 0.25 | 영업시간 KST 경계 — UTC→KST 변환·18:00 정각·자정·주말 | - |
| `misc_edges` | 0.20 | 언어 변형·첨부 크기 경계·누락 필드 | - |
| `signature` | 0.15 | route 가 dict 하나를 받아 str 반환 + 입력 dict 불변 | - |

판정 철학: held-out 40케이스의 기대값은 골든 산출(cases.json)로 고정된다. gate 는
보이는 테스트와 같은 난이도 — 그걸 못 하면 작업을 안 한 것이고, 점수의 70%는
규칙 명세의 예외 교차·시간대 경계를 실제로 읽고 구현했는가에서 나온다.
