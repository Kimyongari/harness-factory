# 코드베이스 주장 목록

온보딩 문서 초안에서 발췌한 주장 10개다. 각 주장이 `src/` 의 현재 코드와
일치하는지 감사가 필요하다.

1. 디스패처는 대기 중인 메시지를 flush 한 번에 최대 50개 단위 배치로 나눠 전송한다.
2. `send_with_retry` 는 일시적 전송 실패(`TransportError`) 시 최대 5회까지 재시도한다.
3. 재시도 사이의 대기 시간은 시도 횟수에 따라 지수적으로(2^attempt 초) 늘어난다.
4. dedupe 캐시 엔트리는 기록된 지 300초가 지나면 만료된다.
5. 같은 `dedupe_key` 가 캐시에 살아 있는 동안 도착한 중복 메시지는 전송이 생략되고
   status 는 "skipped" 로 기록된다.
6. `NOTIFY_LOG_LEVEL` 환경변수가 설정돼 있지 않으면 로그 레벨은 config 기본값인
   WARNING 으로 유지된다.
7. 파싱할 수 없는 payload 는 그것만 버려지고 나머지 메시지 처리는 계속된다.
8. `parse_payload` 는 형식 오류를 로깅한 뒤 예외를 호출자에게 다시 던진다.
9. 전송에 성공한 메시지의 `dedupe_key` 는 캐시에 기록된다.
10. `flush` 가 돌려주는 결과 리포트는 message id 오름차순으로 정렬돼 있다.
