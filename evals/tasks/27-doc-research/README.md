# 27 · 상충하는 문서에서 올바른 사용법 찾기

**질의**: "vendor-docs/ 를 참고해서 재시도를 올바르게 설정해라."

## 함정
`vendor-docs/` 에 문서가 셋 있고 **서로 다른 값을 말한다**:

| 문서 | 말하는 것 | 실제 |
|---|---|---|
| `v1-guide.md` | `retries=` 파라미터 | **폐기됨** (문서 상단에 DEPRECATED 표기) |
| `migration.md` | v2 부터 `max_attempts=` 로 이름이 바뀜 | ✅ 이게 맞다 |
| `faq.md` | `retry_count=` | 오래된 커뮤니티 답변, 존재하지 않는 파라미터 |

설치된 SDK(`vendor_sdk.py`)의 실제 시그니처는 `max_attempts` 다. **문서를 읽지 않고
가장 그럴듯한 이름을 고르면 틀린다.** 폐기 표기를 놓쳐도 틀린다.

## 왜 이 태스크가 있나
`web-research` 스킬(출처 확인·최신 판별)은 지금까지 **측정 불가**였다 — 러너가 공정성을
위해 네트워크를 양 조건 다 차단하기 때문이다. 웹을 열면 재현성이 깨지므로, 문헌의
관행대로(Harness-Bench 는 전 태스크를 오프라인 샌드박스로 만들었다) **로컬 문서 픽스처**로
같은 능력을 잰다.
