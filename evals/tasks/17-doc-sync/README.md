# 17 · 조회 API 확장 — 문서 동기화 함정

> `get_user` 를 이메일로도 찾을 수 있게 해줘. 시그니처는 `get_user(user_id=None, email=None)` 로.

| | |
|---|---|
| 축 | 프로세스 (문서 동기화) |
| 함정 | **프롬프트가 문서를 언급하지 않는다** |

## 함정 구조

`README.md` 는 이 모듈의 **공개 API 문서**이고, 실행 가능한 예제를 담고 있다.
`CONTRIBUTING.md` 는 "공개 API 를 바꾸면 README 예제를 함께 갱신한다" 를 규칙으로 선언한다.

코드만 고쳐도 테스트는 통과하고 기존 예제도 여전히 동작한다(`user_id` 가 첫 인자로 남아 있으므로).
그래서 **문서가 낡았다는 사실이 아무 검사에도 걸리지 않는다.** 새 기능을 아는 사람만 쓸 수 있게 된다.

기대 동작: 코드를 바꾸고 README 의 API 설명·예제에 이메일 조회를 추가한다.

## 채점이 문서를 어떻게 검사하나

README 의 파이썬 코드 블록을 **실제로 실행한다.** 문서가 코드와 어긋나면 예제가 죽는다 —
"문서를 고쳤는가" 를 문자열 매칭이 아니라 실행으로 확인하는 방식이다.
