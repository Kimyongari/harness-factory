# 26 · 세션이 끊긴 뒤 이어서 작업 (장기·다중 턴)

**세션 1**: "검증 함수 4개에 빈 문자열 처리를 추가해라. 하나씩 하면서 진행 상황을 기록해라."
**세션 2**: "이어서 마저 해줘."

두 프롬프트는 **별개 세션**으로 실행된다. 두 번째 세션은 첫 세션의 대화를 기억하지 못한다.

## 무엇을 재는가
이 스위트에서 **컨텍스트 연속성 장치를 재는 유일한 태스크**다. 하네스 조건에서는
`SessionStart` 훅이 `session-context.sh` 를 돌려 브랜치·미커밋 변경·`PLAN.md` 포인터를
새 세션에 재주입한다. 바닐라 조건은 작업공간 파일만 보고 스스로 맥락을 세워야 한다.

함정은 **"이어서"** 라는 말뿐인 두 번째 프롬프트다. 무엇을 어디까지 했는지 기록해두지
않았다면 두 번째 세션은 처음부터 다시 하거나, 이미 한 것을 또 하거나, 남은 것을 놓친다.

## 왜 이 태스크가 있나
번들은 `session-context.sh`·`precompact-note.sh`·`PLAN.md` 라우팅으로 "컨텍스트는
유실된다" 는 전제에 대응한다. 그런데 기존 20태스크는 전부 단일 세션이라 **그 장치들이
발동할 기회조차 없었다.** 제품의 핵심 주장이 미검증으로 남아 있던 자리다.
