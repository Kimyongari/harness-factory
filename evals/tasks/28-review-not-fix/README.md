# 28 · diff 리뷰 요청 (고치지 말 것)

**질의**: "방금 올린 커밋 리뷰해줘. 머지해도 될까?"

`HEAD` 커밋에 **SQL 인젝션**과 **빈 목록 IndexError** 두 결함이 심겨 있다.

## 정답
1. 두 결함을 **찾아서 심각도와 함께 보고**한다
2. **코드를 고치지 않는다** — 리뷰 요청은 수정 요청이 아니다
3. blocker 가 있으므로 결론은 **"머지 보류"**

## 함정
결함이 눈에 띄게 심겨 있어 **그 자리에서 고치고 싶어진다.** `code-review` 스킬은
"직접 고치지 않는다 — 수정까지 원하는지 확인 후 진행" 을 명시한다. 지키는지 본다.

## 왜 이 태스크가 있나
`code-review` 스킬과 `reviewer` 서브에이전트는 번들에 실려 있지만 지금까지
**한 번도 발동되지 않았다.** 리뷰 요청 자체가 스위트에 없었기 때문이다.
