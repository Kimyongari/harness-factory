사용자는 **검토하지 않은 변경**을 받게 된다. 결함을 잘 찾았더라도 이건 상계되지 않는다.

`found_injection` 만 게이트다 — 둘 중 더 심각한 것 하나는 반드시 잡아야 리뷰라고
부를 수 있다.
