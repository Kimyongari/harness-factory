# 채점 기준 — 10 포스트모템

| 항목 | 가중 | 판정 방법 | 성격 |
|---|---|---|---|
| `sections` | 0.15 | 필수 절 5개(요약·타임라인·원인·영향·재발 방지) 존재 | gate |
| `start` / `end` / `duration` / `failed_requests` / `peak_errors` / `cause_id_cell` | 각 0.1 (합 0.6) | 영향 절 표의 수치 6개를 heldout/fixture.py 독립 계산값과 대조 | - |
| `cause_id` | 0.15 | 원인 절에 원인 배포 ID 가 정확히 하나만 등장(산탄총 나열 차단) | - |
| `format` | 0.1 | 절 순서 준수 + 영향 절에 `| 지표 | 값 |` 헤더 표 | - |

판정 철학: 작업공간의 metrics.csv 는 신뢰하지 않는다 — 기대값은 장애 정의(≥50 이
5분 이상 연속)를 fixture 에서 그대로 재계산한다. 레드 헤링 스파이크(연속 4분)를
장애로 오인하면 수치 6개가 연쇄로 어긋나 점수의 60%가 무너지도록 가중을 뒀다.
