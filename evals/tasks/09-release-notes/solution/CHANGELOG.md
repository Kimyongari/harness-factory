## [0.5.0] - 2026-08-06

### Breaking
- 설정 포맷을 TOML 로 전환, config.yaml 은 더 이상 읽지 않음 (#31)
- 만료된 API 키를 게이트웨이에서 거부, 유예기간 키는 401 반환 (#44)

### Added
- 빌링 리포트 CSV 내보내기 (#12)
- OAuth 디바이스 플로 로그인 지원 (#18)
- 프로젝트별 웹훅 시크릿 (#23)
- Slack 알림 채널 (#40)
- 예약 리포트 일시정지 (#47)
- 대시보드 다크 모드 (#55)
- 파일 업로드로 멤버 일괄 초대 (#62)

### Fixed
- 사용량 집계 중복 행 제거 (#15)
- 스케줄러 타임존 처리 수정 (#19)
- 429 응답에서 재시도 폭주 중단 (#27)
- 댓글 미리보기 HTML 이스케이프 (#34)
- 대용량 내보내기 후 워커 메모리 해제 (#51)
- 리다이렉트 시 쿼리 파라미터 보존 (#58)
