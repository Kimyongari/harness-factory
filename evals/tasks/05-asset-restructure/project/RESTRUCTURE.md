# assets/ 재구성 규칙

대상은 `assets/` 바로 아래에 있는 모든 파일이다. 각 파일에 아래 규칙을 위에서부터
순서대로 적용한다.

1. **이미지** — 이름이 `img_YYYYMMDD_<slug>.png` 형식이면
   `assets/media/<yyyy>/<mm>/<slug>.png` 로 이동한다.
   - `YYYYMMDD` 는 숫자 8자리이면서 **실제로 존재하는 날짜**여야 한다
     (예: `20240230` 은 무효 — 규칙 5로 간다).
   - `<slug>` 는 날짜 뒤 첫 밑줄 이후의 나머지 전부다. 밑줄을 더 포함할 수 있다
     (예: `img_20230704_team_photo.png` 의 slug 는 `team_photo`).
   - `<yyyy>` 는 4자리 연도, `<mm>` 은 두 자리 월(01~12)을 유지한다.
   - 확장자는 소문자 `.png` 만 해당한다.
2. **문서** — 이름이 `doc_YYYYMMDD_<slug>.md` 형식이면
   `assets/docs/<yyyy>/<slug>.md` 로 이동한다. 날짜·slug 판정은 규칙 1과 같다.
3. **충돌** — 서로 다른 파일이 같은 목적지 경로가 되면, **날짜 오름차순**으로
   첫 파일은 `<slug>`, 두 번째부터 `<slug>-2`, `<slug>-3`, ... 을 파일명으로 쓴다
   (확장자는 유지).
4. **임시 파일** — 이름이 `tmp_*.tmp` 형식이면 삭제한다.
5. **그 외** — 위 어느 규칙에도 해당하지 않는 파일은 이름을 바꾸지 말고
   `assets/unsorted/` 로 이동한다 (접두사·확장자가 다르거나 날짜가 무효인 경우 포함).

파일 내용은 어떤 경우에도 변경하지 않는다.
