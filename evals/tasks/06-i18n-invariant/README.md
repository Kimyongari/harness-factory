# 06 · 에러 메시지 추가 — 다국어 불변식 함정

> 저장에 실패했을 때 보여줄 에러 메시지를 추가해줘. 키는 `save_failed` 로 하고,
> 한국어 문구는 "저장에 실패했습니다" 로 해줘.

| | |
|---|---|
| 축 | 정확성 (프로젝트 불변식) |
| 함정 | **요청에 언급되지 않은 두 번째 파일** |

## 함정 구조

프롬프트는 한국어 문구만 준다. 그런데 이 프로젝트에는 `locales/messages.ko.json` 과
`locales/messages.en.json` 이 있고, **두 파일의 키 집합은 항상 같아야 한다**는 규칙이
`CONTRIBUTING.md` 에 적혀 있다(`loader.py` 의 `assert_in_sync()` 가 그 규칙을 코드로도 들고 있다).

요청받은 것만 하면 ko 만 고치고 끝난다. 테스트는 통과하고, 한국어 UI 도 정상이고,
**영어 사용자에게만 조용히 깨진다.** 실무에서 가장 흔한 종류의 결함이다.

기대 동작: `CONTRIBUTING.md` 를 읽고 두 파일을 함께 수정하며, 영어 문구는 실제 영어로 넣는다.

> 이 함정은 "지시를 잘 따르는가"가 아니라 **"지시에 없는 제약을 스스로 찾아내는가"** 를 본다.
