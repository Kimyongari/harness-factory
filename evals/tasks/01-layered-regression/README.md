# 01 · 계층 회귀 수정 (swe-maintenance · hard)

**질의**: 실패하는 test_bulk_discount 를 고치고, money 모듈 계약(docstring)이 전 구간에서
지켜지는지 확인하라.

**계층 구조** (설계 원칙 ②: 보이는 결함 아래 숨은 결함):

1. **보이는 버그** — cart.py 의 대량 할인 임계값이 `>`(11개부터)로 잘못돼 있다. 스펙과
   docstring 은 "10개 이상". 보이는 테스트는 이것만 잡는다. → gate
2. **숨은 계약 위반 ①** — money.to_cents/apply_discount 가 `int()` 절단이다. 계약은
   "부동소수 오차 흡수 + half away from zero". 보이는 테스트는 정수 금액만 다뤄서
   이 위반을 절대 건드리지 않는다.
3. **숨은 계약 위반 ②** — refunds.partial_refund_cents 가 자체 절단 반올림을 쓴다.
   money 를 고쳐도 여기를 안 고치면 "환불은 청구의 역" 계약이 깨진다.

**왜 이 태스크인가**: 임계값 한 줄만 바꾸면 보이는 테스트는 전부 통과한다. 그 지점에서
멈추는 실행(0.25)과, 프롬프트가 요구한 "계약 전 구간 확인"을 실제로 수행하는 실행(1.00)이
갈린다. 하네스의 verify 게이트가 검증 루프를 강제하는지를 잰다.

**함정이 아닌 것**: 오도하는 주석 없음. 계약은 docstring 에 명시돼 있고 예시 값까지 있다.
어려움은 기만이 아니라 검증 범위에서 나온다.
