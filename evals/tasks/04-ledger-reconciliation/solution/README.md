# 채점 기준 — 04 은행-장부 대사

| 항목 | 가중 | 판정 방법 | 성격 |
|---|---|---|---|
| `contract` | 0.15 | discrepancies.csv 존재 + 헤더 `txn_id,kind,bank_cents,books_cents` 정확 | gate |
| `recall` | 0.25 | 심은 불일치 12건을 (txn_id, kind) 로 전부 탐지 — 1센트 차이 2건이 관문 | - |
| `precision` | 0.25 | 과잉 보고 0 — 날짜 하루 밀림 3건을 넣으면 여기서 떨어진다(중복 행도 실패) | - |
| `amounts` | 0.2 | 부호 정규화 정수 센트 컬럼 정확(빈 칸 포함) | - |
| `format` | 0.15 | txn_id 오름차순·4컬럼·kind 어휘·센트 표기 형식 | - |

판정 철학: 기대 집합은 픽스처에 심은 역할표에서 직접 생성해 파서 구현과 독립이다.
집합 판정을 재현율/정밀도로 나눈 것은 "레드 헤링 포함"과 "진짜 누락"이라는 서로 다른
실패를 구분해 기록하기 위해서다. gate 는 산출물 계약의 최소선.
